## Overview

**MarkdownBlog** is a lightweight, production‑ready blog platform built with modern JavaScript (ES 2023). 
It supports:

- RESTful API for creating and retrieving posts
- Markdown rendering using **marked**
- Centralised configuration via **dotenv**
- Structured logging with **winston**
- Comprehensive error handling
- Unit & integration tests with **Jest** and **SuperTest**
